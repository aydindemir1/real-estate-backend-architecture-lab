Day dosyaları açıklamaları tekrar etmez; canonical konu dokümanlarına referans verir.

İlk kapsam:
- Day 1–7: initial knowledge inventory
- Day 8 ve sonrası: her Day sonunda zorunlu Knowledge Base impact review
